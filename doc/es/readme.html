Conversor de divisas para NVDA

Versión: 1.2.1

Autor: Arash <arash@ancadper.com>

Conversor de divisas es un complemento para NVDA que permite convertir importes entre monedas usando la API pública de Frankfurter.

Características

  • Ventana accesible desde el menú Herramientas de NVDA.
  • Conversión de divisas usando Frankfurter API.
  • Lista de monedas cargada desde la API y ordenada alfabéticamente.
  • Historial de conversiones recientes solo durante la sesión actual de NVDA.
  • Gestos de entrada configurables, sin atajos asignados por defecto.
  • Conversión rápida desde un gesto, pidiendo la cantidad y copiando el resultado al portapapeles.
  • Interfaz en inglés por defecto, con traducción española incluida.

Uso

Abre el menú NVDA, Herramientas, Conversor de divisas. Introduce la cantidad, elige la moneda de origen y la moneda de destino, y pulsa Convertir.

El botón Intercambiar cambia entre sí las monedas seleccionadas.

La lista de conversiones recientes es de solo lectura y se limpia al cerrar o reiniciar NVDA.

Gestos de entrada

El complemento no asigna atajos de teclado por defecto. Puedes configurarlos desde NVDA, Preferencias, Gestos de entrada, Conversor de divisas.

Privacidad

Cuando conviertes una cantidad, el complemento envía a Frankfurter API la cantidad, la moneda de origen y la moneda de destino. No envía información personal ni el historial.

El complemento solo guarda localmente la última cantidad y las últimas monedas seleccionadas. El historial de conversiones recientes es temporal y se limpia al cerrar o reiniciar NVDA.

Aviso de exactitud

Los resultados son aproximados y pueden no coincidir con comisiones bancarias, tarifas comerciales o casas de cambio.
